## Sobre

Sou estudante de Ciência da Computação na UVA, com foco em front-end e objetivo de atuar como desenvolvedor fullstack. Este repositório tem o código do meu portfólio, com apresentação, skills, projetos, trajetória e contato.

## Destaques

- Layout responsivo para celular, tablet e desktop, com menu hambúrguer
- Sem frameworks e sem build, só HTML, CSS e JavaScript
- Cores e fontes centralizadas em variáveis CSS
- Menu que acompanha a seção visível na tela
- Animações leves, que respeitam `prefers-reduced-motion`

## Estrutura

```text
portfolio/
├── index.html
├── css/style.css
├── js/main.js
└── assets/        # foto.jpg e curriculo.pdf
```

## Como rodar

```bash
git clone https://github.com/seu-usuario/portfolio.git
cd portfolio
```

Abra o `index.html` no navegador ou use a extensão Live Server do VS Code.
